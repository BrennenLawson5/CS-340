# CS-340

I try to write programs in a way that someone else could come back later and understand what is happening without having to guess. For this class and the projects, one way we did that was by keeping the database work inside the CRUD Python module instead of putting all of that logic directly into the dashboard. The module handled the connection to MongoDB and the database operations, while the dashboard focused on showing the data and responding to the user's filter choices. Using the CRUD module from the first project made the second project easier to build because I didn't have to start over. I was able to reuse the same database connection structure and build the dashboard on top of it. This made the code more adaptable because if something about the database changed later I could update the module instead of changing every part of the dashboard. 

I approach problems as a computer scientist by first figuring out what the problem is really asking for before jumping into the code. With both the projects in this course, Grazioso Salvare didn't just need a table of animal records. What they needed was a way to find dogs that matched certain rescue-training profiles, so I really needed to pay attention to the breed, age, sex, and rescue category requirements before building the filters. The second project required me to take everything we had worked on before, and some new stuff, and bring it all together to deliver what Grazioso Salvare was really asking for. Overall, I had to connect the database, the Python Module, the dashboard layout, the filter options, the data table, the chart, and the map all together. A good approach that I use and I think everyone should use is to break the work and requirements into smaller parts. Doing this makes it easier to build what you are being asked to build and it also allows you to test bit by bit, which overall helps to reduce confusion and errors. 

Computer scientists use technology to study problems, design solutions, and make systems work better for people. Their overall purpose is not just to write code, but to find better ways to organize information, automate tasks, improve decision-making, and solve problems that would be difficult or time-consuming to handle manually. They use tools like databases, software applications, algorithms, and user interfaces to turn raw data into something useful. This matters because technology can reduce everyday inconveniences and help solve larger real-world problems. A computer scientist might build an app that helps people access services faster, create a database system that organizes important records, or design a dashboard that helps an organization make better decisions. In every case, the goal is to use technology to make a process more efficient, accurate, and accessible.

For a company like Grazioso Salvare, this project shows how computer science can support meaningful work. Instead of having to manually search through thousands of animal shelter records, the dashboard lets users filter the data by rescue type and quickly see matching dogs, breed patterns, location information, and more. This helps the organization save time and focus on dogs that may be strong candidates for rescue training. In the real world, this kind of system is something that could help Grazioso Salvare work more efficiently and ultimately support rescue efforts that save human lives.
